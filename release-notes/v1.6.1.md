# TypeType for Android 1.6.1

TypeType for Android 1.6.1 is a corrective release for playback seeking.

The application is still in beta.

## Playback

- Coalesce rapid repeated seek requests while keeping the first seek immediate.
- Cancel obsolete SABR window loads and apply only the final requested position.
- Keep playback from advancing through several pending seek generations during rapid scrubbing.

## Validation

- The corrective path was validated in the `1.7.0-beta.5` channel after rapid repeated seeks.
