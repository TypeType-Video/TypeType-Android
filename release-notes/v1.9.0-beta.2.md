# TypeType for Android 1.9.0-beta.2

TypeType for Android 1.9.0-beta.2 fixes channel avatars that disappeared after loading, and brings the loading animation of the web client to thumbnails as well as avatars.

This is a beta build on the 1.9 line.

## Loading placeholders

- Keep channel avatars visible once loaded, after a beta.1 regression that removed them from the layout.
- Animate video thumbnails with the same pulsing placeholder as avatars while they load, on video cards, related videos, continue watching, playlists, and the horizontal cards.
- Use one skeleton primitive across the application, tinted from the foreground color like the web client, instead of the previous surface tint.
- Retry a failed channel avatar up to two times with a distinct cache key, then fall back to the channel initial.

## Everything from beta.1

- Play YouTube lives from the server live manifest, fall back to the SABR route when the bootstrap cannot serve a video, and play Niconico and BiliBili provider media handles.
- Add previous and next video controls to the player, and keep the favorite and watch later state synchronized with the library.
- Show card placeholders while the home, search, and subscription feeds load, and details placeholders while a video loads.
- Enable bullet comments on BiliBili, and label scheduled lives as not started instead of reporting a delivery failure.
- Add subscription notifications with UnifiedPush, plus a local check every fifteen minutes.
- Grey out the accent color picker when the Dynamic theme is selected.
- Prewarm SABR playback when a card is shown, and skip that prewarm for live videos.
- Keep Android 6.0 through Android 17 support, API 23 through API 37, and fix a crash on Android 6.0 caused by the JVM URL encoder.
