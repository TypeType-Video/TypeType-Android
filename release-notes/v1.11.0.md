# TypeType for Android 1.11.0

TypeType for Android 1.11.0 brings personalized recommendations, new video alerts that work, and playback that repairs itself instead of stopping on an error. The app was also reorganized into modules, and the public repository now builds without any private dependency.

## Playback and recovery

- Recover from mid-playback SABR stalls, server timeouts and lost sessions in place, without restarting the video.
- Resume playback after a long pause, when the server has already closed the idle session.
- Keep retrying after network loss and resume as soon as the connection returns.
- Fix frequent buffering: the next part of the video is now requested as early as in the web player.
- Wait as long as the server asks before retrying, and retry when the server is rate limited.
- Avoid a codec only after a definite decoder rejection, and remember only those across launches.
- Replace the double-tap seek wave with a panel that adds up repeated seeks.

## Recommendations

- Turn on personalized recommendations from the home page when the instance offers them, shown as titled rows with the reason for each row, like the web app.
- Say a video is not for you, and tell whether the home page suits you.
- Recommendations have their own entry in Settings, with the same sections as the web app: overview, algorithm, guide, data used, what it keeps, details and your opinions.
- Choose the algorithm and its settings, see what your home page is made of, pin, hide or stop counting an interest or a channel, and choose which data it may read.
- When the instance has the recommender but its admin has not offered it yet, Settings explains it instead of staying silent.

## Notifications

- Choose which subscribed channels send new video alerts, or turn them all on or off at once.
- Show the video title, its thumbnail and its platform in alerts, for YouTube, Bilibili and NicoNico.
- Group a burst of new videos into a single alert, and skip members-only videos, Shorts, live streams and upcoming premieres.
- Recommend Sunup when no UnifiedPush distributor is installed.

## App updates

- App updates have their own entry in Settings: see your version and whether an update is available, choose F-Droid, GitHub Stable or GitHub Beta as the update channel, and read what's new.
- Verify the checksum, package, version and signing certificate of an update before opening Android's installer, and resume interrupted downloads.

## Everyday fixes

- Hide unknown view, subscriber and video counts instead of showing -1, and show scheduled premiere times for upcoming videos.
- Retry metadata when related videos or counts are missing.
- Open videos from links ready to play when the app is already running.
- Start faster and scroll Shorts more smoothly.

## Android TV

The Android TV client now lives in its own repository, [TypeType-TV](https://github.com/TypeType-Video/TypeType-TV), and talks to TypeType-Server directly. The TypeType-SDK is abandoned: this repository no longer contains a TV module or depends on the SDK, so a clean public checkout builds.

## Installing

Download the signed APK attached to the release, or install TypeType through the stable channel of the TypeType F-Droid repository. The stable and beta F-Droid channels use the same application identity, so switching channels updates the existing installation.

If something does not work correctly, please open an issue in the [TypeType-Android repository](https://github.com/TypeType-Video/TypeType-Android/issues).

If you want to support TypeType Android, sharing it with others is the best way to help. You can also sponsor the project: https://github.com/sponsors/Priveetee
