# TypeType for Android 1.9.0

TypeType for Android 1.9.0 brings more reliable playback and subscription notifications, smoother loading states, and new player controls. It also moves the Android app from beta to stable.

## Search

- Switch between YouTube, BiliBili, and NicoNico directly from search.
- Keep the selected service in effect while searching and browsing suggestions.

## Playback and providers

- Play YouTube live streams from the server-provided live manifest, with a fallback when the SABR bootstrap cannot serve a video.
- Play Niconico and BiliBili media handles with the correct video and audio formats.
- Add previous and next video controls, and keep favorite and watch later state synchronized with the library.
- Prewarm SABR playback for video cards, autoplay, and Shorts to help playback start sooner, while skipping unnecessary prewarm work for live videos.
- Show provider access failures as unavailable content and label scheduled live streams as not started.
- Improve player transitions and remove the black strip during the pull-down gesture.

## Loading and appearance

- Use animated skeleton placeholders for feed cards, thumbnails, video details, and channel avatars instead of blank areas while content loads.
- Retry failed channel avatars and keep loaded avatars visible while lists update.
- Keep the accent color control disabled when Dynamic theme is selected.

## Comments

- Enable bullet comments on BiliBili, alongside NicoNico.

## Notifications

- Add subscription notifications with UnifiedPush, a channel bell, and a dedicated notification settings screen.
- Register the Web Push encryption keys required by the server to deliver UnifiedPush notifications.
- Check for new subscription videos locally every fifteen minutes, including when UnifiedPush is registered.

## Compatibility

- Support Android 6.0 through Android 17, API 23 through API 37.
- Fix a crash on Android 6.0 caused by URL encoding.
- Keep core behavior independent from Google Play Services.

## Installing

Download the APK attached below, or install TypeType through the stable channel of the TypeType F-Droid repository. The APK is built from the tagged source, signed by the release workflow, checked for 16 KiB page alignment, and verified against the Gradle application version. A SHA-256 checksum is provided alongside it.

The stable and beta F-Droid channels use the same application identity. Switching channels updates the existing installation instead of installing a second TypeType application.

If something does not work correctly, please open an issue in the [TypeType-Android repository](<https://github.com/TypeType-Video/TypeType-Android/issues>).

If you want to support TypeType Android, sharing it with others is the best way to help. GitHub Sponsors also helps cover the server, domain, and coffee costs that keep the project moving.
