# TypeType for Android 1.4.0

TypeType for Android 1.4.0 brings new account features from TypeType-Server
while keeping the same APK compatible with older instances.

The application is still in beta. Thank you to everyone testing it and sharing
useful feedback.

## What is new

- Create and manage private RSS feeds from your subscriptions when supported by
  your instance.
- Choose whether an RSS feed includes every subscription or selected channels,
  and which types of content it contains.
- Hide live streams from the subscriptions feed on compatible instances.
- Clearer YouTube sign-in availability and recovery, scoped to the active
  account and instance.
- Support for TypeType instances running on local network addresses.
- More reliable subscription feeds after temporary server or network outages.
- Better audio-track defaults, Shorts transitions and playback cleanup when the
  app is removed from recent apps.
- Simpler channel discovery controls.

New settings appear only when the connected TypeType-Server supports them.
Older instances remain usable without RSS or the new subscription filter.

TypeType for Android remains compatible with Android 6.0 through Android 17 and
does not require Google Play Services.

If you encounter a problem, please open an issue in the
[TypeType-Android repository](https://github.com/TypeType-Video/TypeType-Android/issues).
