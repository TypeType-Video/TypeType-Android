# TypeType for Android 1.10.0

TypeType for Android 1.10.0 focuses on more dependable playback, image loading, and server connections. It also adds server-managed recommendation settings and improves fullscreen gesture handling.

## Playback and recovery

- Prepare smaller SABR windows at startup and after seeks, then grow the buffer progressively to improve forward and backward seek recovery.
- Retry failed stream loading when network connectivity returns.
- Keep loading and error artwork from covering the title and channel details in the collapsed player.

## Images and gestures

- Retry visible channel avatars and thumbnails with bounded backoff, and keep loaded images visible while content refreshes.
- Add top and bottom dead zones for fullscreen gestures and respect system safe areas, reducing conflicts with Android system gestures.

## Notifications

- Include the UnifiedPush subscription's `p256dh` and `auth` encryption keys when registering a device with the server.

## Recommendations

- Manage the server's recommender from Content settings when the instance advertises support.
- Preserve unrelated server settings when changing the recommender setting.

## Self-hosted servers

- Add an explicit opt-in for connecting to self-hosted instances over HTTP, including private Tailscale setups. The app warns that HTTP traffic is unencrypted.

## Android TV

This is a mobile Android release. The TV client remains a separate experiment, not a supported public TV release. Its UI and SDK integration are still being worked on, and the current module depends on the private TypeType-SDK, so a clean public checkout cannot build it. This release does not provide a public TV APK or supported external build path. See the [Android TV request](https://github.com/TypeType-Video/TypeType-Android/issues/30) and the [build limitation report](https://github.com/TypeType-Video/TypeType-Android/issues/96).

## Installing

Download the signed APK attached to the release, or install TypeType through the stable channel of the TypeType F-Droid repository. The stable and beta F-Droid channels use the same application identity, so switching channels updates the existing installation.

If something does not work correctly, please open an issue in the [TypeType-Android repository](https://github.com/TypeType-Video/TypeType-Android/issues).

If you want to support TypeType Android, sharing it with others is the best way to help. GitHub Sponsors also helps cover the server, domain, and coffee costs that keep the project moving.
