# TypeType for Android 1.5.0

TypeType for Android 1.5.0 brings a much more complete Shorts experience, deeper player interactions and improvements across comments, subscriptions, navigation and self-hosted instances.

The application is still in beta.

## Shorts

- Rebuild Shorts playback with smoother transitions, faster startup and more reliable paging.
- Reuse prepared playback sessions and prefetched streams when moving between Shorts.
- Swipe from a Short to open its channel, with haptic feedback and controls that remain available during the gesture.
- Copy titles, view engagement details and use more complete playback controls directly from Shorts.
- Keep the active Short prioritized while preparing the next videos in the background.

## Playback

- Add more complete fullscreen controls and improve transitions between embedded, expanded and fullscreen playback.
- Restore the embedded player correctly after leaving expanded playback.
- Improve gestures for seeking, volume and brightness, and remember the selected brightness level.
- Restore system bars and orientation more reliably when playback ends or fullscreen closes.
- Add continuous player motion while dragging between expanded and minimized positions.
- Identify live replays from their stream metadata instead of presenting them as upcoming broadcasts.
- Normalize shared URLs, video metadata and player menu state.

## Comments

- Open comments directly from the player quick actions.
- Load paginated and nested replies without replacing the conversation already on screen.
- Improve comment timestamps, likes, interactive text, loading states and error presentation.

## Subscriptions

- Refresh subscription feeds without hiding useful cached content during temporary failures.
- Keep subscription caches and refresh generations separated between accounts and instances.
- Preserve typed Server errors and request IDs in subscription diagnostics.
- Add coverage for live-feed pagination, cache recreation and stale refresh protection.

## Navigation And Interface

- Keep Search, top-level navigation and restored application state in sync more reliably.
- Clean up layouts for channels, playlists, podcasts, notifications, settings and player details.
- Correct playlist and video counts and improve content metadata presentation.
- Refine settings hierarchy and channel discovery without hiding capabilities supported by the connected instance.

## Self-Hosted Instances And Authentication

- Trust certificate authorities installed by the user, making private and locally hosted HTTPS instances easier to use.
- Show a clearer connection error when an instance certificate cannot be trusted.
- Persist refreshed authentication cookies before process exit to reduce unnecessary sign-ins after process recreation.

## Performance And Compatibility

- Add Macrobenchmark coverage for Shorts paging and playback prefetch budgets.
- Keep newer Server capabilities discoverable at runtime while preserving compatibility with older TypeType-Server versions.
- Support Android 6.0 through Android 17 without requiring Google Play Services.
